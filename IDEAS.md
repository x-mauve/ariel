# Идеи для нотификатора

## Отправка
- **Форматирование** — параметр `parse_mode` (`MarkdownV2`/`HTML`), чтобы выделять важное.
- **Без звука** — флаг `disable_notification` для некритичных уведомлений.
- **Уровень важности** — параметр `level` (`info`/`warn`/`error`) с префиксом-эмодзи (ℹ️ ⚠️ 🔴).
- **Длинные сообщения** — разбивать текст длиннее 4096 символов на несколько сообщений.
- **Файлы** — инструмент `sendDocument` для логов и отчётов.

## Управление сообщениями
- **Редактирование** — `editMessage` по `message_id`, чтобы обновлять статус («⏳ собираю…» → «✅ готово»).
- **Удаление** — `deleteMessage` для устаревших уведомлений.
- **Закреп** — `pinMessage` для самого важного.

## Получатели
- **Несколько чатов** — именованные чаты из env (`TELEGRAM_CHATS=me:123,team:456`) и параметр `chat` в инструменте.

## Надёжность
- **Ретраи** — повтор при 429 с учётом `retry_after` и при сетевых ошибках.
- **Таймаут** — `context.WithTimeout` на каждый запрос.
- **Проверка токена** — вызов `getMe` при старте, чтобы сразу падать с понятной ошибкой.

## Прочее
- **Отложенная отправка** — параметр `delay`/`at` (таймер в памяти процесса).
- **Подтверждение** — inline-кнопки с ожиданием ответа через `getUpdates` (уже не совсем «простенький»).
